# 🚗 WebCarros

**WebCarros** é uma aplicação web para simulação de venda de carros, desenvolvida com **React**, **TypeScript** e **Vite**, utilizando **Tailwind CSS** para estilização, **Zod** para validações de formulário e **Firebase** como banco de dados.

## 🔧 Tecnologias utilizadas

- [React](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Zod](https://zod.dev/) — validação de formulários
- [Firebase](https://firebase.google.com/) — banco de dados, autenticação, etc.

---

## 📁 Estrutura do projeto

``` 
/
├── public/               # Arquivos estáticos
├── src/
│   ├── components/       # Componentes reutilizáveis
│   ├── pages/            # Páginas da aplicação
│   ├── services/         # Conexão com Firebase
│   └── App.tsx           # Componente principal
├── tailwind.config.js    # Configuração do Tailwind
├── vite.config.ts        # Configuração do Vite
├── tsconfig.json         # Configuração do TypeScript
└── package.json
```


---
## ✅ Funcionalidades

✅ Listagem de veículos disponíveis
✅ Cadastro e simulação de venda de carros
✅ Validação de dados com Zod
✅ Integração com Firebase para dados persistentes e autenticação
✅ Interface responsiva com Tailwind CSS
